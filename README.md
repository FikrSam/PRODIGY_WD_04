# PRODIGY_WD_04 - Personal Portfolio

This repository contains the source code for my personal portfolio, developed as part of the Prodigy InfoTech Web Development Internship (Task 4). 

## Project Structure

This repository is split into two implementations of the same aesthetic terminal-inspired design:

1. **Root Directory (HTML/CSS/JS)**:
   The original, vanilla web implementation using raw HTML, CSS, and JavaScript. 
   - `index.html`: The main page structure
   - `styles.css`: The styling, featuring glassmorphism accents and strict monochrome/custom font design
   - `script.js`: Logic for the custom tracking mouse "sentinel" cursor

2. **React-portfolio Directory**:
   A complete refactor of the original design into a modern React application using Vite.
   See the README inside the `React-portfolio` folder for setup and run instructions.

## Key Features
- Terminal-inspired minimalist aesthetic
- Custom interactive tracking cursor
- Smooth snap-scrolling sections
- Fully responsive layout
- Modern typography using 'JetBrains Mono' and 'Inter'
